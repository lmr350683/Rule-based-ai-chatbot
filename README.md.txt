# Rule-Based AI Chatbot

## Project Description
This is my first Artificial Intelligence project. It is a simple rule-based chatbot developed using Python. It responds to predefined user messages using conditional statements.

## Project Objectives
- Handle greetings and exit commands.
- Use if-elif-else logic to select responses.
- Run continuously using a while loop.
- Handle messages that the chatbot does not recognize.

## Features
- Responds to hello, hi, and hey.
- Answers questions about its name.
- Responds to "How are you?"
- Provides a help message.
- Handles unknown messages.
- Exits when the user types bye, exit, or quit.

## Technologies Used
- Python 3
- Command Prompt
- GitHub

## How to Run
1. Install Python 3.
2. Open Command Prompt.
3. Navigate to the project folder.
4. Run the command: `py chatbot.py`
